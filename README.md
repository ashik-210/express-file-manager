# Express File Manager

A simple file management web application built using **Node.js, Express.js, EJS, and Tailwind CSS**.

This project allows users to create, view, and rename text files through a simple web interface.

## 🚀 Features

* Create text files
* View file content
* Rename files
* Display all available files
* Express routing
* EJS templates
* Tailwind CSS styling
* Static file serving

## 🛠️ Technologies Used

* Node.js
* Express.js
* EJS
* Tailwind CSS
* File System (`fs`) module
* HTML

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ashik-210/express-file-manager.git
```

Go inside the project:

```bash
cd express-file-manager
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node app.js
```

Open in your browser:

```text
http://localhost:3000
```
